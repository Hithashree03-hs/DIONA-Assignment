How to run

No build step and no dependencies — open index.html directly, or serve the folder locally:

# Option A — Python
python -m http.server 5500        # then open http://localhost:5500

# Option B — Node
npx serve .

💡 To export a PDF: open an exercise → Print / Save PDF → destination "Save as PDF" → enable Background graphics. Margins are handled by the page itself.
